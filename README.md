## Описание проекта
Данный репозиторий содержит материалы выполнения лабораторных и практических работ:
- **ЛР 1-4:** Архитектура ИС, Docker-контейнеризация, Git и CI/CD
- **ЛР 5-8:** Базы данных MS SQL Server, миграции, резервное копирование и Nginx Reverse Proxy
- **ЛР 9-12:** Мониторинг Prometheus, дашборды Grafana, Alertmanager и сбор логов Loki
- **ЛР 13-16:** Нагрузочное тестирование k6, безопасность, автоматизация Ansible
- **ЛР 17-20:** Оркестрация контейнеров в Kubernetes (k3s), ConfigMap, Ingress и отказоустойчивость
